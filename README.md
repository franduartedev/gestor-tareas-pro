# Gestor de tareas

Ejercicio web en JavaScript para agregar tareas con prioridad y mostrar su estado.

## Tecnologías

- HTML
- CSS
- JavaScript

## Ejecutar localmente

No requiere instalación de paquetes. Desde la carpeta del proyecto, iniciá un servidor estático:

```bash
python -m http.server 8000
```

Abrí [http://localhost:8000](http://localhost:8000).

## Estado y limitaciones actuales

- Se pueden agregar tareas con título y prioridad.
- El estado inicial es pendiente.
- Los controles de marcar como completada aún no actualizan el estado.
- Las tareas no persisten al recargar la página.

El nombre del repositorio no implica que se trate de un producto terminado.
